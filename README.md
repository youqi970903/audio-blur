# Audio Blur v1.0.1

将当前 Chrome 标签页的声音变成模糊的背景音。音频在浏览器本地实时处理。

## 本地安装

1. 使用 Chrome 116 或更新版本。解压下载的 ZIP。
2. 打开 `chrome://extensions`。如果已安装旧版 Audio Blur，先关闭旧版的开关，测试页面中如果还在播放，刷新一次。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 打开一个视频页面，点击 Chrome 工具栏中的 Audio Blur 图标，再开启面板里的开关。

开关和实时强度按标签页独立控制。关闭效果会结束该标签页的音频捕获，让 Chrome 恢复原声。新标签页从最近一次保存的强度开始。Chrome 可能会在启用效果时显示标签页正在共享音频的指示。

这个 ZIP 是可加载的扩展源码。若要更新 Chrome 网上应用店中的现有版本，请在原扩展的开发者后台上传 ZIP。
